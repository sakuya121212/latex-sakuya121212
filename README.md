# LaTeX Project Creator

このリポジトリは、LaTeXプロジェクトを簡単に作成するためのツールです。`make project`コマンドを使用して、新しいLaTeXプロジェクトを自動生成できます。

## 機能

- プロジェクト名の入力に基づいて新しいディレクトリを作成
- テンプレートファイル（`template.tex`）をコピーしてプロジェクト名で置換
- 基本的なLaTeXドキュメントの構造を提供

## 使用方法

1. リポジトリをクローンまたはダウンロードします。
2. ターミナルでリポジトリのルートディレクトリに移動します。
3. 以下のコマンドを実行します：

   ```bash
   make project
   ```

4. プロンプトが表示されたら、作成するプロジェクト名を入力します（例: `my_paper`）。
5. `projects/`ディレクトリ内に新しいプロジェクトディレクトリが作成され、LaTeXファイルが配置されます。

## 例

```bash
$ make project
作成するプロジェクト名を入力してください: my_paper
プロジェクトを作成しました: projects/my_paper
```

作成されたプロジェクトには、`my_paper.tex`ファイルが含まれ、基本的なLaTeXテンプレートが適用されています。

## 必要な環境

- Bashシェル
- LaTeX環境（例: TeX Live, MiKTeX） - 生成された.texファイルをコンパイルするために必要

## ファイル構造

- `Makefile`: `make project`コマンドの定義
- `scripts/create_tex_project.sh`: プロジェクト作成スクリプト
- `projects/templates/template.tex`: LaTeXテンプレートファイル
- `projects/`: 生成されたプロジェクトが保存されるディレクトリ

## 注意事項

- プロジェクト名が空の場合、作成は中断されます。
- 同じ名前のプロジェクトが既に存在する場合、作成は中断されます。
- テンプレートは基本的なarticleクラスを使用しています。必要に応じてカスタマイズしてください。
